# Universal POS - React Web Dashboard

Modern web dashboard for the Universal POS system built with React

## Features

- User Authentication
- Dashboard Overview
- Product Management
- Order Tracking
- Sales Reports
- Real-time Data
- Responsive Design

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm start
```

3. Build for production:
```bash
npm run build
```

## Configuration

Update API URL in components (currently http://localhost:5000)

- Username: admin
